Ce que Relais est

Un incubateur qui reste jusqu’au produit. Un studio qui ne vole pas l’idée. Moins cher en capital qu’un startup studio parisien. Plus concret qu’un accompagnement classique.

Hexa prend 33 % à la création, 25–30 % après le seed. Nous prenons ~10 % et vous gardez l’idée.
Accompagnement + construction Métier déjà en activité Talents sans cash pour passer à l’acte SaaS d’abord, app ensuite — ou app dédiée

Le trou

Les programmes existent. Le produit, rarement.

Incubateurs, écoles, réseaux : ils aident à structurer. Les agences livrent un site. Les startup studios créent la boîte contre 25 à 30 %. Relais est l’étage manquant : exécuter le produit avec vous.

Deux portes d’entrée

Le métier qui vend déjà. Le talent qui n’a pas encore les moyens.

Même offre. Même exigence : une solution identifiée, un porteur valide, un marché accessible. Relais n’est pas le spin-off d’un programme existant. Les programmes saturent le conseil. Relais ouvre l’aval produit.

Léa — indépendante métier

Des clients, une communauté, une app en tête. Bloquée au conseil et au devis. Elle sait quoi faire. Elle ne peut pas le construire.

Noa — potentiel, pas encore l’acte

Idée solide, énergie, souvent déjà passé par un programme. Pas les finances pour une agence, pas de CTO. Relais sort le produit.

Méthode

Starter. Build. Scale.

01 · 4 semaines

Starter

Valider. Landing. Porte go / no-go. Gratuit, sélectif. On n’écrit pas de code pour une idée vague.

02 · 8 à 16 semaines

Build

On code le MVP. SaaS d’abord, app ensuite — ou app dédiée si le mobile est le job. Vous restez CEO.

03 · 6 mois

Scale

Vendre. Pricing. Juridique. Abo 249 € HT / mois. Relais n’achète pas vos clients à votre place.
